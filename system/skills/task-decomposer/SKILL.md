# Task Decomposer

## When to use
Activate when the user gives a broad, complex, or ambiguous objective (e.g. "build a feature", "launch marketing campaign", "redesign architecture").

## Procedure
1. Clarify the core desired outcome and boundaries.
2. Break down the goal into 3-7 discrete, sequential stages:
   - Specification and research
   - Core implementation / action
   - Verification and acceptance testing
3. For each sub-task, define:
   - Clear title (action verb + object)
   - Specific input preconditions
   - Definition of Done (testable acceptance criteria)
4. Register tasks using `create_task` or present the roadmap for user review.
