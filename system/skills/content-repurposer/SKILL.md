# Content Repurposer

## When to use
Activate when the user provides a raw idea, link, article, or transcript and wants to generate multi-channel social media content.

## Procedure
1. Identify the core thesis, hook, and key insight from the input.
2. Adapt the content for target platforms:
   - **Telegram:** Engaging narrative, key takeaways, formatting with bold/lists.
   - **Twitter / X:** Punchy hook tweet (<= 280 chars) followed by numbered thread (`1/n`).
   - **LinkedIn:** Professional perspective, business impact, bullet points, call-to-action.
3. Validate character limits for each platform before suggesting publication.
4. Offer to schedule or publish directly using `composio_post` once confirmed by the user.
