# Morning Briefing 2.0

Используй этот скилл, когда пользователь просит утреннюю сводку, дайджест на день или когда запускается утренний cron-брифинг.

## Порядок сбора данных (выполняй параллельно)

1. **Погода**: вызови `jarvis_weather` для города пользователя (если не указан в памяти/запросе, используй город из `jarvis_memory_search` или уточни один раз и сохрани).
2. **Календарь**: вызови `composio_calendar` (или `composio_action` с `GOOGLECALENDAR_EVENTS_LIST`) на сегодня (`timeMin` = начало дня, `timeMax` = конец дня) и выдели встречи с временем и ссылками.
3. **Почта**: вызови `composio_gmail` (`GMAIL_FETCH_EMAILS`, `max_results=10`, фильтр `is:unread newer_than:1d`), сгруппируй по срочности (требует ответа / уведомления / рассылки).
4. **GitHub**: вызови `composio_github` для проверки открытых PR, назначенных ревью и непрочитанных уведомлений.
5. **Задачи Kanban**: вызови `jarvis_task` со списком текущих задач (`status: todo, in_progress, review`), выдели просроченные и приоритетные на сегодня.

## Формат итогового брифинга

Выдай компактную, структурированную сводку на русском языке:
- **Погода и одежда**: кратко температура, осадки, совет.
- **Фокус дня (Top 3)**: 3 главные задачи из Kanban и встреч.
- **Расписание**: список встреч на сегодня по времени.
- **Почта и GitHub**: только то, что требует внимания или решения.

## Доставка в Telegram (опционально)

Если брифинг запущен по расписанию или пользователь просит прислать сводку в мессенджер, отправь краткую версию через `jarvis_notify` (`title: "Утренний брифинг"`, `level: "info"`).
